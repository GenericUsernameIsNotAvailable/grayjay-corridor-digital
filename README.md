# Corridor Digital Plugin for Grayjay

Browse and watch publicly accessible Corridor Digital shows, seasons, and episodes in Grayjay Android (no account required; DRM-protected videos are excluded).

## Installation

### Option 1: Install via Grayjay Sources Directory
Once listed, open [grayjay-sources.github.io](https://grayjay-sources.github.io/) on your Android device and tap **Install** next to **Corridor Digital**.

### Option 2: Direct URL (Grayjay App)
1. Open **Grayjay** on Android and go to **Sources** -> **Add Source**.
2. Copy and paste this URL:
```text
[https://raw.githubusercontent.com/GenericUsernameIsNotAvailable/grayjay-corridor-digital/main/CorridorConfig.json](https://raw.githubusercontent.com/GenericUsernameIsNotAvailable/grayjay-corridor-digital/main/CorridorConfig.json)
